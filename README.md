# MRK Translate

Seç, kısayola bas, çevrilsin — Windows için çeviri kısayolları ve Toplantı Altyazısı.

## Kurulum

[Son sürümün sayfasından](https://github.com/avmehmetkaragoz/mrk-translate/releases/latest) `MRKTranslate-Kurulum.exe`'yi indirip çift tıkla. Yönetici izni istemez.

- İlk açılışta Windows "bilgisayarınızı korudu" diyebilir: **Ek bilgi → Yine de çalıştır**.
- Kurulu program güncellemeleri buradan kendiliğinden alır.
- Yapay zekâ özellikleri için Ayarlar → Motor → **API Anahtarı** (OpenRouter).

Bu depo yalnızca sürümleri içerir.
